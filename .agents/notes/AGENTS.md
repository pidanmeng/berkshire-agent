# AGENTS.md — Agent Notes

Agent Notes 实质上是 AI 写的 RFC：耐久的提案与决策记录，保存决策依据、备选方案、后果与必需的验证。遵循[仓库文档标准](../../AGENTS.md)与 [Agent Note 规则](README.md)。

**每份新 Agent Note 都触发一次超驰（supersession）检查。** 搜索活跃目录树中覆盖同一决策或机制的旧记录，用 [`bk-archive-agent-notes`](../skills/bk-archive-agent-notes/SKILL.md) 判定每项全/部分超驰，并在同一 PR 内归档每个符合归档条件的 implemented 记录。部分超驰保留 active 并交叉链接。

[`archived/`](archived/AGENTS.md) 下的文件是冻结的历史快照：永不可编辑，也不得视为当前权威。
